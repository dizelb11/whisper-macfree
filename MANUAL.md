# Руководство

Полное описание: что это, как поставить, что происходит при первом запуске
и почему запрашиваемые разрешения безопасны.

---

## Что это

Диктовка голосом для macOS. Зажимаете **Fn**, говорите, отпускаете — текст
появляется там, где стоит курсор. В любом приложении: браузер, мессенджер,
редактор, терминал.

Аналог Wispr Flow и SuperWhisper, только распознавание идёт на вашей машине,
а не на чужом сервере. Ни аккаунта, ни подписки, ни оплаты за использование.

**Что нужно:**

- Mac на Apple Silicon — M1 или новее. На Intel не работает: библиотека MLX
  считает на встроенном GPU Apple и на процессорах Intel не запускается.
- macOS 14 или новее
- [Homebrew](https://brew.sh)
- около 8 ГБ свободного места (модели занимают 4 ГБ, остальное — окружение)

---

## Приватность: что программа может и чего не может

Раздел стоит прочитать до установки. Программа просит два серьёзных
разрешения, и вы вправе понимать, зачем.

### Куда девается звук

Запись идёт во временный файл, оттуда — в распознавание, и **файл сразу
удаляется**. Звук не сохраняется, никуда не отправляется и нигде не копится.

Сохраняется только текст — в историю на вашем диске, чтобы можно было найти
и поправить сказанное. Она лежит в
`~/Library/Application Support/whisper-local/history.db` и никуда не уходит.

### Про интернет

Сеть нужна ровно один раз — скачать модели при установке. После этого
распознавание работает полностью офлайн: можно выдернуть Wi-Fi и всё
продолжит работать.

В коде приложения сетевых обращений нет вообще, а демон слушает только
локальный Unix-сокет, к которому нельзя подключиться снаружи машины.

### Микрофон

Нужен, чтобы записывать вашу речь. Пишет только пока зажата клавиша —
не фоном, не постоянно. Индикатор записи в строке меню macOS показывает,
когда микрофон активен, и это индикатор системы, а не наш.

### Универсальный доступ — самое важное

Это мощное разрешение, и относиться к нему стоит серьёзно: оно позволяет
программе следить за нажатиями клавиш и управлять другими приложениями.
Выдавайте его только тому, чему доверяете.

Здесь оно нужно для двух вещей:

1. **Заметить нажатие Fn**, когда вы в другом приложении. Без этого горячая
   клавиша работала бы, только если наше окно активно, что бессмысленно.
2. **Вставить текст** — программа кладёт текст в буфер обмена и посылает
   Cmd+V, после чего возвращает буфер как было.

**Чего программа при этом не делает — и это проверяемо в исходниках:**

- **не видит, что вы печатаете.** Перехватчик подписан ровно на одно событие
  — `flagsChanged`, изменение клавиш-модификаторов (Fn, Shift, Cmd). Обычные
  символы в этот поток не попадают физически. Смотрите `mac/Sources/Dictate/HotKey.swift`.
- **не читает содержимое чужих окон.** Только вставляет.
- **не работает в полях пароля.** macOS включает там защищённый ввод, и
  программа это проверяет и отказывается вставлять.

Вы собираете программу из исходников на своей машине, так что всё сказанное
можно проверить, а не принимать на веру. Файлов немного, читаются за полчаса.

## Установка

### Одной командой

```bash
curl -fsSL https://raw.githubusercontent.com/dizelb11/whisper-macfree/main/bootstrap.sh | bash
```

Склонирует проект в `~/whisper-macfree` и всё поставит. Займёт минут
пятнадцать, почти всё время — загрузка моделей.

Не любите выполнять скрипты из интернета не глядя — и правильно делаете.
Тогда так:

```bash
git clone https://github.com/dizelb11/whisper-macfree.git
cd whisper-macfree
less install.sh    # почитать, что он собирается делать
./install.sh
```

Дальше — [что происходит при первом запуске](#первый-запуск-какие-окна-появятся).

### По шагам, вручную

Если хотите понимать, что происходит, или ставить по частям — ниже то же
самое, разобранное на шаги.

### Шаг 1. Проверить, что железо подходит

```bash
uname -m && sw_vers -productVersion
```

Должно быть `arm64` и версия 14 или выше. Если `x86_64` — у вас Intel,
дальше идти бессмысленно.

### Шаг 2. Инструменты сборки

```bash
xcode-select --install
```

Ставит Command Line Tools — компилятор Swift, которым собирается приложение.
Если уже стоят, команда скажет об этом. Полный Xcode не нужен, хватает
инструментов командной строки (около 1 ГБ вместо 15).

### Шаг 3. ffmpeg

```bash
brew install ffmpeg
```

Нужен для чтения звуковых файлов — библиотека распознавания вызывает его
внутри себя.

### Шаг 4. Забрать проект

```bash
git clone https://github.com/dizelb11/whisper-macfree.git
cd whisper-macfree
```

### Шаг 5. Окружение Python

```bash
python3 -m venv .venv
.venv/bin/pip install mlx-whisper
```

Создаёт изолированное окружение внутри папки проекта и ставит туда
распознавание. Системный Python не затрагивается — всё лежит в `.venv/`
и удаляется вместе с папкой.

Если хотите ещё и причёсывание текста локальной моделью:

```bash
.venv/bin/pip install mlx-lm
```

### Шаг 6. Собрать приложение

```bash
./mac/bundle.sh
```

Компилирует Swift-код и собирает `Dictate.app`. Скрипт подписывает
приложение локальной подписью — она нужна, чтобы macOS запомнила выданные
разрешения.

### Шаг 7. Скачать модель

```bash
.venv/bin/python3 daemon/whisperd.py
```

Первый запуск качает модель распознавания — 1,5 ГБ, несколько минут. Когда
увидите `слушаю ...` — готово, можно прервать через Ctrl+C.

Если ставили `mlx-lm`, скачайте заодно и модель причёсывания, иначе она
подтянется при первом нажатии Shift и вы несколько минут будете гадать,
сломалось или нет:

```bash
.venv/bin/python3 -c "from mlx_lm import load; load('mlx-community/Qwen3-4B-Instruct-2507-4bit')"
```

### Шаг 8. Автозапуск

```bash
./install-autostart.sh
```

Прописывает запуск демона и приложения при входе в систему. Демон держит
модель в памяти — без этого каждая диктовка ждала бы её загрузку несколько
секунд вместо полусекунды.

Не хотите автозапуск — пропустите шаг и запускайте вручную через `./run.sh`.

### Шаг 9. Отдать клавишу Fn

**Системные настройки → Клавиатура → «Нажатие 🌐» → «Ничего не делать».**

По умолчанию macOS вешает на эту клавишу свою панель эмодзи или системную
диктовку и забирает нажатие себе. Пока это не изменить, до программы Fn
не дойдёт.

## Установка с помощью ИИ

Если не хочется разбираться с командами — скопируйте текст ниже целиком в
Claude Code, ChatGPT с доступом к терминалу или другого помощника,
умеющего выполнять команды на вашем компьютере.

```
Помоги установить whisper-macfree — локальную диктовку для macOS.
Репозиторий: https://github.com/dizelb11/whisper-macfree

Действуй по шагам и после каждого показывай, что получилось:

1. Проверь, что у меня Mac на Apple Silicon (uname -m должно дать arm64)
   и macOS 14 или новее. Если нет — остановись и скажи, что не подойдёт.
2. Проверь наличие Homebrew, Command Line Tools и ffmpeg. Чего нет — поставь.
3. Склонируй репозиторий в удобную папку и запусти ./install.sh
4. Если установщик упадёт — покажи ошибку и разберись, не пропускай шаг.
5. После установки объясни своими словами, какие разрешения запросит
   система, зачем каждое нужно и что мне нажимать.
6. Напомни про настройку клавиши: Системные настройки → Клавиатура →
   «Нажатие 🌐» → «Ничего не делать».

Не выполняй команды с sudo без моего явного согласия и объясни заранее,
зачем такая команда нужна, если понадобится.
```

Последний абзац оставьте: он не даёт помощнику молча выполнять действия,
требующие пароля.

## Первый запуск: какие окна появятся

Порядок может отличаться, но окна будут эти.

### «Программа Dictate запрашивает доступ к микрофону»

**Нажать «Разрешить».** Без микрофона записывать нечего.

Отказались случайно — Системные настройки → Конфиденциальность и
безопасность → Микрофон → включить Dictate.

### «Программа Dictate запрашивает разрешение на управление компьютером»

Это Универсальный доступ, разобранный выше: нужен, чтобы заметить Fn и
вставить текст.

**Нажать «Открыть Системные настройки»** и включить переключатель у Dictate.
Окно можно закрыть — программа сама заметит выдачу за пару секунд, иконка
в строке меню сменится с 🔐 на 🎙.

Окно не появилось — откройте вручную: меню иконки → **Разрешения macOS…**

### Значок в строке меню

| значок | что значит |
|---|---|
| 🎙 | готов, можно диктовать |
| 🔴 | идёт запись |
| 🟣 | идёт запись, текст будет причёсан |
| ⋯ | распознаёт |
| 🔐 | ждёт Универсальный доступ |
| ⚠️ | ошибка — наведите мышь, покажет причину |

## Как пользоваться

**Зажать Fn, сказать, отпустить.** Текст появится там, где курсор.
Примерно полсекунды после отпускания.

Говорите обычным голосом, диктовать по слогам не нужно — наоборот, хуже.
Знаки препинания расставляются сами.

### Два режима

В меню иконки → **Настройки** выбирается, что делает Fn:

- **Обычная диктовка** — быстро, около 0,6 секунды.
- **С причёсыванием** — около 2,5 секунды. Локальная модель убирает «э-э» и
  «короче», правит пунктуацию, пишет термины латиницей: «клод код» становится
  `Claude Code`.

**Shift, зажатый вместе с Fn, всегда даёт противоположный режим** — лезть в
настройки ради одной диктовки не нужно.

Причёсывание работает не идеально, поэтому стоит ограничитель: если модель
сменила язык, дописала лишнего или переписала больше 40% слов — её правка
отбрасывается и вставляется исходный текст. В истории видно, что она
предлагала и почему её остановили.

Первое причёсывание после включения компьютера ждёт около 12 секунд —
подгружается вторая модель. Дальше 2,5 секунды.

### История

Меню иконки → **История диктовок**. Список сказанного, правится прямо в
строке. Под текстом показывается, что услышало распознавание, если итог
отличается — видно, что именно было понято не так.

### Словарь

Меню иконки → **Настройки**. Там две вкладки, и они решают разные задачи.

**«Мои слова»** — список того, что вы часто произносите: названия проектов,
имена, термины, жаргон. Распознавание узнаёт про эти слова заранее и
перестаёт их коверкать. Впишете `Claude Code` — и вместо «клод кот» будет
писаться правильно.

Это основной инструмент, обычно его достаточно.

**«Исправления»** — на случай, когда подсказка не сработала. Слева пишете,
как слово услышалось, справа — на что заменить. Замена происходит уже в
готовом тексте.

Что именно было услышано, видно в истории диктовок: там под текстом
показывается исходное распознавание, если итог от него отличается.

Заменяется только слово целиком: правило «прот» → «прод» не тронет
«напротив» или «протокол».

Изменения применяются со следующей диктовки. В подсказку помещается около
120 слов — ограничение модели распознавания, не наше.

Насколько это важно: на замере словарь поднял долю правильно распознанных
терминов с 57% до 87%.

## Если что-то не так

Причина почти всегда в логах:

```bash
tail -20 "$HOME/Library/Application Support/whisper-local/dictate.log"
tail -20 "$HOME/Library/Application Support/whisper-local/whisperd.log"
```

**Иконка 🔐 не меняется на 🎙.** Разрешение выдано не тому файлу. Так бывает
после пересборки: подпись локальная и привязана к содержимому программы.
Лечится одной командой, после неё выдайте разрешение заново:

```bash
./mac/regrant.sh
```

**Fn не срабатывает.** Проверьте настройку клавиши 🌐 (шаг 9). Если рядом
работает другая программа диктовки — Wispr Flow, SuperWhisper — выйдите из
неё: две программы на одной клавише сработают обе.

**Вставляется не туда или ничего.** В полях пароля вставка заблокирована
системой намеренно. В остальных случаях — посмотрите лог приложения.

**Иконка ⚠️.** Наведите мышь, в подсказке будет причина.

**Долго думает.** Проверьте, что демон жив: `pgrep -f whisperd.py`.
Если пусто — `./run.sh`.

## Как удалить полностью

```bash
./uninstall-autostart.sh                                  # автозапуск
pkill -f whisperd.py; pkill -f Dictate                     # процессы
rm -rf "$HOME/Library/Application Support/whisper-local"   # история, словарь, модели WhisperKit
rm -rf ~/.cache/huggingface/hub/models--mlx-community--whisper-large-v3-turbo
rm -rf <папка проекта>
```

Отдельно снимите разрешения: Системные настройки → Конфиденциальность и
безопасность → Универсальный доступ и Микрофон → убрать Dictate.
