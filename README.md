# whisper-local

Диктовка голосом для macOS. Зажал **Fn** — сказал — отпустил, текст под курсором.

Всё считается на вашей машине: ни аккаунтов, ни подписок, ни отправки звука
наружу. Замена Wispr Flow и SuperWhisper с нулевой стоимостью эксплуатации.

- распознавание Whisper large-v3-turbo, ~0,6 сек после отпускания клавиши
- словарь терминов, чтобы «клод код» становилось `Claude Code`
- по желанию — причёсывание текста локальной моделью (~2,5 сек)
- история диктовок с правкой

## Установка

Нужен **Mac на Apple Silicon** (M1 и новее), macOS 14+, [Homebrew](https://brew.sh)
и около 8 ГБ свободного места.

```bash
curl -fsSL https://raw.githubusercontent.com/dizelb11/whisper-macfree/main/bootstrap.sh | bash
```

Или, если не хотите запускать скрипт из интернета не глядя:

```bash
git clone https://github.com/dizelb11/whisper-macfree.git
cd whisper-macfree && less install.sh && ./install.sh
```

Скрипт проверит систему, поставит зависимости, скачает модели, соберёт
приложение и настроит автозапуск. Займёт минут пятнадцать — большая часть
уходит на загрузку моделей (1,5 ГБ распознавание, ещё 2,5 ГБ если
согласитесь на причёсывание).

**[Подробное руководство](MANUAL.md)** — установка по шагам с объяснениями,
разбор запрашиваемых разрешений, что делать при первом запуске и как
пользоваться. Там же промпт для установки с помощью ИИ, если не хочется
разбираться с командами.

Два действия придётся сделать руками, их автоматизировать нельзя:

1. **Системные настройки → Клавиатура → «Нажатие 🌐» → «Ничего не делать»**,
   иначе macOS заберёт Fn себе.
2. Разрешить приложению **Универсальный доступ** и **микрофон**, когда попросит.

## Как пользоваться

| | |
|---|---|
| **Fn** | зажать, говорить, отпустить — текст вставится под курсор |
| **Shift** вместе с Fn | противоположный режим (см. настройки) |
| меню иконки 🎙 | история диктовок, настройки |

В настройках выбирается, что делает Fn: обычную диктовку (~0,6 с) или
с причёсыванием локальной моделью (~2,5 с — убирает «э-э» и «короче»,
правит пунктуацию, пишет термины латиницей). Shift всегда даёт другой режим,
так что ради одной диктовки в настройки лезть не нужно.

Иконка показывает состояние: 🎙 готов, 🔴 пишет, 🟣 пишет с причёсыванием,
⋯ расшифровывает, 🔐 ждёт разрешения, ⚠️ ошибка (наведите — покажет причину).

### Словарь

Меню иконки → Настройки → «Словарь». Таблица из двух колонок: **как надо**
(подсказывается распознаванию заранее) и **как слышится** (заменяется в
готовом тексте, если слово упорно распознаётся неверно).

Замена идёт только по целому слову, так что «прот» → «прод» не тронет
«напротив». Применяется со следующей диктовки.

## Если что-то не так

```bash
tail -20 "$HOME/Library/Application Support/whisper-local/dictate.log"   # приложение
tail -20 "$HOME/Library/Application Support/whisper-local/whisperd.log"  # распознавание
```

Приложение подписано ad-hoc, поэтому **после каждой пересборки выданный
Универсальный доступ перестаёт засчитываться**. Лечится одной командой:

```bash
./mac/regrant.sh
```

Отключить автозапуск: `./uninstall-autostart.sh`

## Как устроено

Swift-приложение в менюбаре ловит Fn, пишет звук и вставляет результат.
Фоновый Python-демон держит модель в памяти и отвечает через Unix-сокет —
иначе каждая диктовка ждала бы загрузку модели несколько секунд.

История и причёсывание живут в демоне, а не в приложении: так они переживают
пересборки, и промпт можно менять без повторной выдачи разрешений.

Выбор моделей сделан не на глаз, а замером на живой речи — методика и цифры
в [bench/RESULTS.md](bench/RESULTS.md). Замер воспроизводим: в `bench/` лежат
образцы фраз, диктофон и счётчик ошибок, так что можно прогнать на своём
голосе и проверить, та ли модель лучше именно для вас.

## Замер (bench/)

Три файла-эталона:

- `phrases.txt` — что **произносится** вслух при записи
- `expected.txt` — что должно **получиться в тексте** (`эс-эс-эйч` → `SSH`)
- `terms.txt` — доменные термины, попадание по которым считается отдельно

Разделение принципиальное: общий WER размазывает ошибку по служебным словам,
а нас интересует, вставился ли `Claude Code` вместо «клод код».

### Прогон

```bash
.venv/bin/python3 bench/record.py                                        # записать голос
.venv/bin/python3 bench/transcribe.py mlx-community/whisper-large-v3-turbo
.venv/bin/python3 bench/transcribe.py mlx-community/whisper-large-v3-turbo --prompt
.venv/bin/python3 bench/score.py
```

`--prompt` подмешивает `dictionary.txt` в `initial_prompt` Whisper. Это проверка
гипотезы, что подсказка вытягивает доменные термины. Окно подсказки у Whisper —
224 токена (~100–150 русских слов), весь словарь туда не влезет, нужен отбор.

### Базовая линия

Синтетический самотест (`score.py --all`) даёт границы:

| прогон | WER | термины |
|---|---|---|
| идеальный текст | 0.0% | 30/30 (100%) |
| сырая речь без словаря | 20.8% | 11/30 (37%) |

Нижняя строка — потолок для ASR без словаря, даже при безошибочном
фонетическом распознавании. Разрыв в 63% терминов закрывает словарь.

## Решения

- **Только локально.** Ни сетевого кода, ни ключей, ни платных API.
  LLM-полировка планируется, но локальной моделью и отдельным хоткеем:
  основная диктовка остаётся мгновенной и бесплатной, а секунды на
  причёсывание тратятся по явному выбору.
- **Движок — mlx-whisper в фоновом демоне.** WhisperKit проверен и отклонён:
  на 17 пунктов хуже по терминам и втрое медленнее (см. bench/RESULTS.md).
- **Обучение — через словарь, не через дообучение модели.** Whisper принимает
  `initial_prompt`, который смещает распознавание. «Стало лучше со временем» =
  словарь наполнился.
- **Никакого чтения чужих полей ввода.** Правки вносятся вручную в окне истории.
- **Swift, нативный .app** — чистые разрешения, менюбар, и тот же ASR-код
  переиспользуется, если дело дойдёт до iOS.
